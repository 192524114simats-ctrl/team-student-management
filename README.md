# Student Management System

## Project Description
This is a team project developed using Git and GitHub.

## Modules
Project Status: Attendance and Marks modules completed.
1. Attendance Module
2. Marks Module

## Branching Strategy
The main branch contains the stable project version.
Each module is developed in a separate feature branch.

## Code Review
Pull Requests are used to review code before merging changes.

## Conflict Resolution
Merge conflicts are resolved by reviewing the conflicting changes
and keeping the correct combined content.

## Team Workflow
1. Create a feature branch.
2. Develop the module.
3. Commit and push changes.
4. Create a Pull Request.
5. Review the changes.
6. Resolve conflicts if necessary.
7. Merge the approved Pull Request.
